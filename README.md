# Exploratory-data-Analysis-EDA-Project
 Exploratory Data Analysis

 Overview

The Exploratory Data Analysis project investigates the book dataset generated by the web scraping project.

The goal is to understand the structure and characteristics of the data before performing further analysis.

The analysis uses Pandas to inspect the dataset and Matplotlib to visualize the distribution of book prices.

 Objectives
Understand the structure of the dataset.
Examine variables and data types.
Identify missing values.
Detect duplicate records.
Calculate descriptive statistics.
Investigate book prices and ratings.
Identify potential price outliers.
Generate meaningful analytical questions and answers.

 
 Technologies Used
Python
Pandas
Matplotlib
NumPy

 
 Analysis Performed

The project examines:

Number of rows and columns
Data types
Missing values
Duplicate records
Mean price
Median price
Average rating
Most expensive books
Rating distribution
Potential price outliers using the IQR method
